# Design Proposal: Tarik Tavera — Premium Custom

## Identidad

Tarik es un geógrafo-activista que traduce datos satelitales en acciones concretas para comunidades amazónicas. No es un consultor de escritorio — va al VRAEM con comunidades Asháninka, vuela drones sobre concesiones forestales, y diseña alertas tempranas para pueblos indígenas. Su superpower: conectar la alta tecnología geoespacial con las realidades humanas del territorio.

## Audiencia

- **Organizaciones internacionales** (ONU, FZS, CARE) → buscan track record + especialidades claras
- **Entidades públicas** (SERNANP, OSINFOR) → buscan credenciales + proyectos previos
- **Academia** (PUCP, colegas) → buscan publicaciones + investigación
- **Clientes de consultoría** → buscan servicios + evidencia de impacto

## Referencia Visual: ayanaelizabeth.com

Replicar la esencia editorial:
- Nav minimalista (iniciales "TT" + hamburger)
- Nombre grande en serif con énfasis italic
- Foto profesional con elemento gráfico (círculo amarillo → para Tarik: forma orgánica verde)
- Bio text-forward, no bullet points
- Secciones limpias, amplias, con mucho whitespace

Adaptar al mundo de Tarik:
- Acento amarillo → verde bosque / sienna marrón
- Editorial → territorial/cartográfico
- Subtle: elementos que evocan mapas, coordenadas, topografía

## Metáfora Visual

El territorio como lienzo — donde las líneas de contorno de un mapa topográfico se convierten en el lenguaje visual del sitio. Verde profundo de dosel amazónico + sienna de tierra expuesta. Editorial como ayanaelizabeth.com pero con el alma de un mapa.

## Visual Language

### Paleta
```
primaryDark:  #1b4332  — Deep forest (headings, nav, footer bg)
primary:      #2d6a4f  — Forest green (borders, tags, accents)
primaryLight: #52b788  — Sage (hover states, subtle highlights)
accent:       #7c4a2d  — Sienna brown (CTAs, stats, emphasis)
surface:      #f2ede6  — Warm cream (section bgs alternating)
surfaceLight: #f8f5f0  — Off-white (hero bg, main bg)
```

### Tipografía
- **Display/Headings:** Cormorant Garamond (serif, editorial authority — like Orpheus in Ayana)
- **Body:** Source Sans 3 (clean, readable, professional)
- **Accent/Quotes:** Cormorant Garamond italic

### Efecto Visual Único
1. **Mapa interactivo embebido** — Google Maps con los markers del cliente (ningún otro portfolio tiene esto)
2. **Forma orgánica verde** overlapping foto en hero (ref: yellow circle in Ayana)
3. **Topographic line pattern** sutil como background texture en secciones alternas (SVG)

### Motion
- Scroll reveals suaves (fade up, 200ms stagger)
- Tag pills hover: slight lift + shadow
- Map section: fade in on scroll
- Timeline dots: sequential draw
- prefers-reduced-motion: solo opacity
